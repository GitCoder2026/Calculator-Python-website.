# Calculator-Python-website.
A basic calculator website made with Python programing language.
in your browser go to http://localhost:8000/?
You will see it does not work and will take you to an error page saying that Local Host refuesed to connect, So to fix this
Open "Or install" Python 3.13 and use the provided code at this link https://docs.google.com/document/d/1UgrNFV2dCiRBN2AeHYy5CbcyLXEEkgcFAkKcd7xgNWk/edit?usp=sharing
Then copy and paste it into your Python 3.13 window and run the code. After this now go to http://localhost:8000/? and your calculator will be running in that tab.
The website will only run when your computer is on.
